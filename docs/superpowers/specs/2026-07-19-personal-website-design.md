# 个人网站设计文档

**日期**: 2026-07-19
**状态**: 已确认,待写实施计划

## 背景与目标

为 Anjie 设计并实现一个个人网站,风格参考 [gracexygu.github.io](https://github.com/gracexygu/gracexygu.github.io),整体走"克莱因蓝 + 浅灰背景"的干净留白编辑感风格。网站包含 7 个板块:Home、About、Experience、Study Diary、Share Life and Insights、Toolkit、Contact。

素材现状:文字、照片、经历详情、日记内容、抖音链接等真实素材**目前都还没有**,本期先用占位内容(占位图 + 示例/说明性文字)把整站结构、交互、视觉都做出来,后续由用户自行替换真实素材。占位图统一用 CSS 渐变色块 + 文字说明标注"应替换什么内容",方便用户之后一眼找到要换的位置。

## 技术选型

纯静态 HTML/CSS/JS,不引入任何构建工具或前端框架,便于直接部署到 GitHub Pages,也方便用户后续自己修改内容。

**站点结构**:多页路由(每个板块是独立的 html 文件),而非单页滚动。每个页面各自包含完整的 `<head>`、顶部导航、页脚,不使用 JS 动态拉取公共头尾片段——这样任何页面都可以直接双击在浏览器打开预览,不依赖本地服务器。代价是修改顶部导航文案时需要同步改 7 个文件,但改动量很小,可接受。

**文件结构**:

```
my-project/
├── index.html          首页(Home)
├── about.html
├── experience.html
├── study-diary.html
├── share-life.html

├── css/
│   ├── base.css         CSS 变量(色彩/字体/间距)、reset、通用排版
│   ├── nav.css          顶部导航条 + 首页呼吸圆环导航样式
│   └── pages.css        各页面专属样式(先合一个文件,过大再按页拆分)
├── js/
│   ├── nav.js           圆环导航文字环绕定位计算、顶部导航当前页高亮
│   ├── experience.js    拍立得扇形卡片堆叠、时间轴联动、卡片翻转逻辑
│   ├── diary.js         日记本封面开合、翻页、分页点状态逻辑
│   └── main.js          全站通用小交互(如卡片 hover 效果)
└── assets/
    ├── images/           占位图片(头像、经历封面、日记配图等)
    └── icons/            svg 图标(email/github/tiktok/箭头/心形等)
```

## 视觉系统

**配色**

| 用途 | 色值 |
|---|---|
| 主色·克莱因蓝 | `#002FA7` |
| 背景·浅灰(偏暖) | `#F5F5F3` |
| 卡片/内容区背景 | `#FFFFFF` |
| 正文文字 | `#2B2B2E` |
| 强调色浅色版(蓝 10% 透明度) | `#E8ECF9` |

蓝色以"点缀式"使用(标题关键词、按钮、图标、线条、光球),不做大面积色块背景(封面等特殊场景除外),保持浅灰底色的留白呼吸感。

**字体**

- 标题/强调:`Playfair Display`(英文)+ `Noto Serif SC`(中文兜底)
- 正文:`Georgia` + `Noto Serif SC`
- 全站统一走衬线字体路线,营造编辑感/杂志感;句子中的关键词用克莱因蓝加粗高亮(参考 About 页 "what if" / "explore" / "mess" 的强调手法)

**动效基调**

- 呼吸/浮动类动画:纯 CSS `@keyframes` + `animation`,时长 4-7 秒,`ease-in-out infinite alternate`
- 翻转类交互(Experience 卡片、圆环 hover 反馈):CSS `transform` + `transition`,JS 只负责切换 class
- 日记翻页:CSS `transition` 做页面整体位移/透视翻转,JS 控制页码状态和按钮禁用态
- 统一使用 `ease-in-out`,时长 0.4s~0.8s,不用 `linear` 或弹跳类缓动,保持克制柔和的气质

## 导航方案

- **顶部导航条**(所有页面统一,包括首页):左侧姓名/logo,右侧文字链接(About / Experience / Study Diary / Share Life / Toolkit / Contact),透明背景、滚动时轻微出现底色。当前所在页面用克莱因蓝下划线高亮。<768px 时右侧链接收进汉堡菜单。这是保底的可靠跳转方式。
- **首页呼吸圆环导航**:作为首页专属的主视觉亮点和额外入口,与顶部导航条指向同一批页面。

## 页面设计

### Home(首页)

- 左右分栏布局。
- 左侧文案依次淡入,衬线字体:
  1. `Hello,`(克莱因蓝大字)
  2. `I'm Anjie, endlessly curious about bringing ideas to life with AI.`(灰色正文)
  3. `Nothing starts perfectly. Everything starts somewhere.`(灰色正文)
- 右侧呼吸圆环导航:
  - 中心一个克莱因蓝渐变光球(径向渐变 + 模糊光晕),两条独立 CSS 动画分别控制"呼吸"(缩放 0.95→1.05 + 透明度变化,约 4-5 秒周期)和"浮动"(缓慢上下漂移,约 6-7 秒周期,与呼吸动画错开周期避免机械感)
  - 光球外围有一条极淡的虚线引导圆环
  - 6 个目录词条(About / Experience / Study Diary / Share Life / Toolkit / Contact)分布在圆周上,每个词条根据所在角度用 `rotate + translate` 定位并保持切线方向(即文字本身随圆周弯曲旋转,不强制保持水平),形成真正的"文字环绕圈"视觉效果
  - hover 时词条变亮、光球轻微加速呼吸一下作为反馈
- 移动端(<768px):圆环导航退化为居中的纵向文字列表,光球缩小作为背景装饰保留呼吸感,不做圆周排布

### About

- 顶部导航条下,主体左右两栏:左侧照片(圆角、柔和阴影,占位图先用灰蓝色块 + 人像图标说明),右侧文字区
- 文字区结构:
  1. 自我介绍标题句(关键词克莱因蓝加粗高亮,参考风格:"I ask **what if** a lot, **explore** things before I understand them...")
  2. 3 个虚线边框的特质标签(大写字母、字间距拉宽、克莱因蓝文字 + 透明背景,占位如 CURIOUS-MINDED / AI-DRIVEN / STRATEGY-MINDED,用户后续替换为自己的特质词)
  3. 正文介绍段落,其中提到的学校/机构名做成克莱因蓝行内强调样式

### Experience(时间轴 + 拍立得扇形卡片)

- 标题区:"02 EXPERIENCE" 风格的编号大写衬线标题(字间距拉宽),旁边一颗小号呼吸蓝光斑做点缀,呼应首页光球
- 主体:多张拍立得样式照片卡(白色相框 + 轻阴影)以扇形叠放展示,教育经历和实习经历按时间顺序混排
  - 当前"激活"的卡片摆正、放大、置于最前
  - 其余卡片按角度错落叠在后面(如 -8°/-4°/4°/8°)
- 卡片正面:占位照片 + 简短说明(机构/公司名 + 角色/专业 + 时间区间)
- 底部横向时间轴:年份刻度分布,一个克莱因蓝位置指示器可拖动或点击年份切换"激活卡片",切换时扇形卡片做相应的重排动画
- **交互规则(两步式)**:
  1. 点击时间轴上的年份,或点击扇形中非激活的卡片 → 将对应卡片带到最前面并摆正(不翻转)
  2. 再次点击当前已激活(最前面)的卡片 → 触发 3D 翻转(`rotateY`,过渡 0.6s ease-in-out),背面展示该段经历的完整文字介绍;再次点击翻回正面
- 移动端(<768px):扇形收起为可左右滑动的单卡轮播 + 同款年份刻度,去掉旋转角度,避免小屏拥挤

### Study Diary(留学日记本)

- **封面入场**:进入页面先看到一本合上的"书封面"——克莱因蓝实底卡片
  - 左下角小字 "STUDY DIARY / 年份"
  - 下方衬线大字标题(如 "Study Diary.")
  - 右侧边缘一个白色圆形"翻开"按钮,点击时按钮变为克莱因蓝(点击态反馈),同时书页展开进入第一篇日记
- **内页布局**:白色圆角卡片模拟摊开的书,中间一条极淡竖向缝线区分左右页
  - 左页:小分类号 + 衬线大标题 + 正文段落(旅行/生活感悟)
  - 右页:纵向堆叠 1-2 张照片
- **翻页控件**:书的左右外侧各一个圆形翻页按钮(‹ ›),平时白色,点击时触发呼吸蓝光反馈;不可用方向(如第一页的"上一页")灰化
- **底部分页指示**:一排小圆点,当前页的点拉长为蓝色胶囊状,下方配 "x / y" 页码文字
- 支持键盘左右方向键翻页
- **内容篇数暂不固定**——先做通用的翻页机制和页面模板(数据结构为 JS 数组,每篇含标题/分类号/正文/图片路径),等用户上传日记内容后再确定具体篇数,先占位 2-3 篇示例内容验证交互

### Share Life and Insights(抖音作品分享)

- **页头**:左上角编号分类标签(与 Experience 编号风格统一,如 "04 — SHARE LIFE"),下方两行衬线大标题 "Share" / "Life & Insights"(第二行克莱因蓝)
- **页头右侧**:一句简短中英双语签名/态度文案 + 数据统计区(粉丝数、获赞数,克莱因蓝粗体数字 + 下方小字灰色标签),数据先放占位数字,等用户有真实抖音数据后替换
- **作品卡片区**:统一网格布局(CSS Grid,`auto-fit/minmax`,窄屏自动变单列),每张卡片放一张占位封面图 + 一句标题文字,点击整张卡片在新标签页打开对应抖音作品/主页链接(先用 `#` 占位)。不做疏密错落的 masonry 布局和点赞图标叠加,等用户后续直接换成抖音截图即可
- 顶部另有一个"关注我的抖音"按钮,链接到抖音主页,新标签页打开
- **底部**:一条细横线 + 居中小字提示语(如"点击查看更多")

### Toolkit(工具箱)

- 上半部分 "Skills":按类别分组的标签云(如 Languages & Frameworks / Design / AI & Prompt Tools),药丸状标签、克莱因蓝细边框,与 About 页特质标签视觉语言一致
- 下半部分 "Projects":卡片网格,每张卡片含项目名、一句话简介、技术标签、GitHub/演示链接图标按钮,占位 3-4 个项目位

### Contact(结尾页)

- 居中简短收尾文案(衬线大字,呼应首页 "Hello,")
- 下方三个联系方式按钮(图标 + 文字):
  - Email:`mailto:` 链接
  - GitHub:链接到主页,新标签页打开
  - TikTok/抖音:链接到主页,新标签页打开
- 背景放一颗极淡、极小的呼吸光斑做视觉收尾呼应,不做完整圆环导航

## 响应式规则

- 断点:768px(平板/手机分界)、1024px(桌面/中等屏分界)
- 首页圆环导航:<768px 退化为居中纵向文字列表
- Experience 扇形卡片:<768px 退化为横向单卡轮播
- 顶部导航条:<768px 右侧链接收进汉堡菜单
- 所有网格类布局(Toolkit 项目卡、Share Life 卡片)使用 CSS Grid 的 `auto-fit/minmax`,窄屏自动变单列

## 无障碍与基础细节

- 占位图统一用 CSS 渐变色块 + 文字说明(如"[Photo placeholder: 关西旅行]"),方便用户之后定位替换
- 圆环导航词条、翻页按钮等交互元素添加 `aria-label`
- favicon 使用简单的克莱因蓝圆点 svg

## 范围之外(本期不做)

- 真实内容素材录入(照片、经历详情、日记正文、抖音链接)——占位内容搭框架,用户后续自行替换
- 抖音视频直接内嵌播放(采用卡片跳转方案代替)
- 构建工具/前端框架接入
- 后端/CMS/表单提交能力(Contact 页仅做静态链接,不做留言表单)
